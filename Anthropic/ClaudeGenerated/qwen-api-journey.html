Inside the model server

Three things happen to your prompt before you see a word. Tokens below are an approximation: the real tokenizer splits text differently.

1Tokenize

Text becomes tokens, the units the model reads and you are billed for.

2Prefill

All input tokens are processed in parallel and kept in a memory called the KV cache.

3Decode

One token is chosen, added to the text, and the model repeats until it stops.

Simplified on purpose. This follows the OpenAI-compatible endpoint of Alibaba Cloud Model Studio (international region shown; other regions use a different host), so OpenAI SDKs work with a changed base URL. Qwen models can also be downloaded and run on your own servers, in which case the gateway and metering stops disappear. Alibaba's internal routing and hardware are not public, so those stops show the general idea of how large language models are served. The reply in this animation is a fixed sample.
