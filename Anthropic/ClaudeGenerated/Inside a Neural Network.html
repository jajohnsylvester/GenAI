How a neural network learns

A neural network is a stack of tiny calculators wired together. Each one weighs its inputs, adds them up and passes a signal on. Learning means adjusting those weights until the answers come out right. Every diagram on this page is live.

Chapter 1

One neuron: weigh, add, squash

Each artificial neuron does three things. It multiplies every input x by a weight w, which says how much that input matters and in which direction. It adds the products together with a bias b, a baseline nudge. Then it passes the total z through an activation function that bends the straight line into a curve.

Drag the sliders. Thicker wires mean bigger weights. The dots flowing along each wire show that input's contribution: orange pushes the neuron up, blue pulls it down.

Why the squash matters

Without an activation function, stacking neurons would still give you one big straight line. The bend is what lets a network draw curved boundaries and model messy, real-world patterns.

Sigmoid squeezes any number into 0 to 1, like a probability. Tanh maps into −1 to 1. ReLU simply zeroes out anything negative, and it is the default in most modern networks because it is cheap and trains well.

Chapter 2

Learning is rolling downhill

To learn, a network needs a score for how wrong it is. That score is the loss. A perfect prediction scores 0, and bigger mistakes score higher.

Picture the loss as a landscape. Every possible weight value is a spot on the ground, and the height is how wrong the network would be with that weight. Training is a search for the lowest valley.

The network can't see the whole landscape. It can only feel the slope under its feet, called the gradient. So it takes a step downhill, measures again, and repeats. That loop is gradient descent:

wnew = w − η × slope

The step size η is the learning rate. Try these:

Press Run from the starting point and the ball settles in the shallow valley on the right, a local minimum. Click further left on the curve and run again to find the deeper valley. Then push the learning rate above 0.8 and watch it overshoot and bounce.

A real network has millions of weights, so its landscape has millions of dimensions. The idea is exactly the same.

Chapter 3

Forward, compare, backward, update

Here is a small but complete network. It has two inputs, three hidden neurons and one output. It tries to predict whether a student passes an exam from hours studied and hours slept, both scaled to 0–1.

One training step runs four stages:

1. Forward pass. Signals flow left to right, layer by layer, until the output neuron gives a prediction.

2. Measure loss. The prediction is compared with the true answer, the target.

3. Backpropagation. The error travels right to left. Using the chain rule from calculus, each weight learns its share of the blame: the gradient ∂L/∂w.

4. Update. Every weight takes a small step against its gradient, which is the downhill step from Chapter 2.

Watch the gold pulses run backward, then the wires change thickness. Press Train 25 rounds and the loss falls toward zero. Flip the target to fail and the network relearns.

Field notes

Words you'll hear

Weight
A number on each connection that scales the signal. Learning means changing weights.
Bias
A per-neuron offset that shifts when the neuron switches on.
Activation
The bend applied to a neuron's sum, such as sigmoid, tanh or ReLU.
Layer
A column of neurons. Hidden layers sit between the input and the output.
Loss
One number that scores how wrong the predictions are.
Gradient
The slope of the loss for each weight: which way is downhill, and how steep.
Learning rate
How big a step each update takes. Too small is slow; too big overshoots.
Backpropagation
The chain-rule bookkeeping that computes every gradient in one backward sweep.
Epoch
One full pass through all the training examples.
