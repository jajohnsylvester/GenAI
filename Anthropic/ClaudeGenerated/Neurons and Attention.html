Wires that are fixed,
wires that are chosen.

A Transformer is a neural network. Both are stacks of weighted sums and simple nonlinear functions, trained the same way. What changes is how information moves: a classic network sends signals down fixed wires, while a Transformer lets every word decide, on the fly, which other words to listen to.

§1 · Neural network · the building block

One neuron: multiply, add, squash

Every neural network, Transformers included, is built from this one operation. Each input is multiplied by a weight, the results are added together with a bias, and the sum passes through an activation function that bends the straight line into a curve. §3 · Transformer · words become vectors

Turn words into numbers, then stamp on their position

Neural networks only read numbers. A Transformer looks each token up in a learned table to get its embedding, a vector that encodes meaning. Real models use thousands of numbers per token; here we show 8. Attention on its own has no sense of order, so a position signal made of sine waves is added to each vector.

§4 · Transformer · self-attention

Every word asks: who here matters to me?

Each token produces a query (what am I looking for?), a key (what do I contain?) and a value (what do I pass on?). Matching one token's query against every key gives a score; a softmax turns the scores into weights that add up to 100%. The token's new vector is the weighted blend of everyone's values. A model runs several heads in parallel, and each learns a different kind of relationship.

§6 · Transformer · output

The last layer is an ordinary classifier

After the final block, a linear layer scores every word in the vocabulary and a softmax turns the scores into probabilities. That is exactly how the network in §2 produced its prediction. Temperature divides the scores before the softmax: low values make the model pick the safest word, high values make it adventurous.

§7 · Side by side

The core difference: fixed wiring vs wiring chosen per input

Feed both models a new sentence. In the classic network the connection strengths never change; only the values flowing through them do. In attention, the connections themselves are recomputed from the input every time.

Sequential vs parallel

Before Transformers, language networks were mostly recurrent (RNNs): they read one word at a time and passed a running summary forward. A Transformer layer handles every word at once and connects each pair directly. That makes it fast on GPUs, at the price of comparing n × n pairs.
