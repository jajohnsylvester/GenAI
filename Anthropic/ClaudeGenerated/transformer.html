Step 1 · Tokenize

Text is chopped into tokens

A model never sees letters. A tokenizer splits text into pieces from a fixed vocabulary and swaps each piece for an integer ID. Common words get one token; rare or long words are split into sub-word pieces (dashed below).

Step 2 · Embed + add position

Each token becomes a vector, stamped with its position

An embedding table maps each token ID to a list of numbers (512 in the original paper, 16 drawn here). Similar words end up with similar vectors.

Attention by itself ignores word order: “dog bites man” and “man bites dog” would look identical. So a positional encoding, a pattern of sine and cosine waves at different frequencies, is added to each vector.

Positional encoding · x = position 0–47 · y = dimension 0–31
PE(pos, 2i) = sin(pos / 100002i/d)    PE(pos, 2i+1) = cos(pos / 100002i/d)

Low dimensions (top) oscillate fast and high dimensions slowly, so every position gets a unique barcode. Hover a token column above to see its slice.

Step 3 · Self-attention

Every token asks a question of every other token

Each vector is multiplied by three learned matrices to make a Query (what am I looking for?), a Key (what do I contain?) and a Value (what do I pass on if chosen?).

A token’s query is compared with every key using a dot product. The scores are scaled, turned into percentages with softmax, and used to take a weighted average of the values. The result is a new vector for that token that carries in context from the words it attended to.

Attention(Q, K, V) = softmax( Q·Kᵀ / √dk ) · V    with dk = 64, so √dk = 8

The full attention matrix

Each row is one query; each column one key. Darker blue means more attention. Hatched cells are hidden by the causal mask: a token may not peek at words that come after it.

Step 4 · Multi-head attention

Several attention patterns run side by side

One attention pattern can only capture one kind of relationship. So the model runs several heads in parallel, each with its own Q, K and V matrices. The original Transformer used 8 heads of 64 dimensions each; 8 × 64 = 512, the model width.

Each head’s output is concatenated, then a final matrix WO mixes them back into one vector per token.

Step 5 · The Transformer block

Attention, then think, with shortcuts around both

Attention moves information between tokens. A feed-forward network then processes each token on its own. Residual connections add each sub-layer’s input back onto its output, and layer normalization keeps the numbers in a stable range. Stack this block 6 times (or 96 times in large models) and you have a Transformer.

Click any box in the diagram to learn what it does.

Layer normalization

Rescales one token’s vector to mean 0 and spread 1, then applies a learned scale and shift. Without it, values drift and training becomes unstable as layers stack up.

Feed-forward network

Expands each vector 4× (512 → 2048), applies a non-linearity that switches many neurons off, then projects back to 512. Most of a model’s stored knowledge lives in these weights.

Step 6 · The whole architecture

Encoder, decoder, and the families they spawned

The 2017 model was built for translation. An encoder reads the full source sentence; a decoder writes the translation one token at a time, using cross-attention to look back at the encoder’s output. Later models kept only one half.

Step 7 · Generate

Predict a token, append it, repeat

The final layer’s vector for the last position is multiplied by a vocabulary-sized matrix, giving one score (a logit) per possible token. Softmax turns the scores into probabilities and one token is chosen. It is appended to the input and the whole sequence runs through the model again.

Temperature divides the logits before softmax. Low values sharpen the distribution toward the top choice; high values flatten it and make output more surprising.

1.00
p(token) = softmax(logits / T)

The attention weights, embeddings and next-token scores on this page are illustrative. They come from small hand-written rules so the patterns are easy to see. A trained model learns all of them from data, and its heads are usually messier.
