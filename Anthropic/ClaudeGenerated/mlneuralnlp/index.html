How machine learning, neural networks and NLP fit together

These three terms get used as if they mean the same thing. They don't. Click a region of the map to see where each one lives, then scroll down to train a real model in your browser.

Part 1 · Machine learning

The four ingredients

Data (the houses), a model (a straight line with two knobs), a loss (how wrong the line is on average) and an optimizer (gradient descent: repeatedly turn the knobs a little in the direction that lowers the loss).

Why it matters

Nobody told the program the slope. It found it. Add a few expensive mansions and train again: the rule changes because the data changed.

Classical ML in the wild

Linear and logistic regression, decision trees, random forests, gradient boosting and k-nearest neighbours. They shine on tidy tables of numbers where people pick the input columns (feature engineering).

The limit

A straight line can only draw straight boundaries. Some patterns curve. That is where neural networks come in.

Part 2 · Neural networks

Stack simple units until they can bend

A neuron multiplies its inputs by weights, adds them up and squashes the result. One neuron draws a straight line. A layer of them, combined, can draw a circle. This network is training live on the dots below.

Forward pass

Inputs flow left to right. Each line is a weight: orange pushes the next neuron up, blue pushes it down, thickness is strength. The output is a probability between 0 and 1.

Backpropagation

After each guess, the error flows backwards through the same lines. Calculus tells every weight how much it contributed to the mistake, and each one gets nudged. It is the same gradient descent loop as Part 1, run across many more knobs.

Try this

Set hidden neurons to 1 on the circle. The network is back to drawing one straight line and gets stuck. Raise it to 4 or more and the boundary curls into a loop.

Deep learning

Real networks have dozens to hundreds of layers and billions of weights. Early layers learn simple features (edges, letter shapes), later layers combine them into concepts. Nobody hand-designs those features.

Why language is hard

"Not bad" is good. "Sick" can be a compliment. Meaning depends on word order, context and tone, which is exactly what simple word-counting misses.

Three eras of NLP

Rules (1960s–80s): grammars and keyword lists. Statistical ML (1990s–2010s): word counts fed to classical models. Neural (2013 onward): embeddings, then transformers with attention, which power today's chatbots and translators.

What all three share

They learn from examples

Modern ML, neural nets and NLP systems all fit their behaviour to data rather than hand-coded logic.

Everything becomes numbers

Table rows, pixels and words all end up as vectors before any learning happens.

Loss + optimization

Each measures how wrong it is and adjusts parameters to be less wrong, usually with gradient descent.

Tested on unseen data

A model is only judged on examples it never trained on, to catch memorizing instead of learning.

They inherit bias

A model learns whatever patterns the data contains, including unfair ones.
