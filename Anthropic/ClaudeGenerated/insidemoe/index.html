How sparse LLMs work

A big brain that only wakes part of itself up.

A Mixture of Experts (MoE) model splits each feed-forward block into many small expert networks. A tiny router picks a few experts for every token, so the model holds hundreds of billions of parameters but only uses a fraction of them per word.

Where the experts live

A transformer layer has attention followed by a feed-forward network (FFN). In an MoE layer, that single FFN is replaced by many parallel FFNs, the experts. Attention stays dense and shared by every token.

1. Router scores

A small linear layer turns the token's hidden state into one score per expert.

2. Top-k selection

Only the k highest-scoring experts run. The rest are skipped, so they cost no compute for that token.

3. Weighted sum

The chosen experts' outputs are blended using the router's weights and passed to the next layer.

Big on disk, light on compute

Each token pays for the shared layers plus k experts. Memory still has to hold every expert, because any token might need any of them. This sketch uses Mixtral-shaped numbers: 1.6B shared parameters and 5.64B per expert.

The failure mode: rich-get-richer routing

Experts that get more tokens train faster, look better to the router, and win even more tokens. Left alone, a few experts take over and the rest are wasted. Training adds a balancing pressure to prevent this. Switch it off and watch.

"Topic shift" sends a burst of tokens that prefer experts 3 and 4, like a sudden run of code. With balancing, the pressure pulls the load back toward an even split. Real systems use an auxiliary loss (Switch Transformer, Mixtral-style training), or, as in DeepSeek-V3, a per-expert bias that is nudged up for under-used experts and down for busy ones.

Few big experts

Mixtral, Grok-1 and Llama 4 Scout use 8 to 16 large experts. Routing is simple and each expert is a full-size FFN.

Many small experts

DeepSeek, Qwen3 and Kimi K2 use 128 to 384 fine-grained experts with top-8. More combinations per token, finer specialization.

Shared experts

DeepSeek, Kimi K2 and Llama 4 keep one or more always-on experts for common knowledge, so routed experts can specialize.
