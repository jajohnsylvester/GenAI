Difference between Tools, Connector, Skills, Plugin and Harness:

1/ Tool: A way in which Claude can do "work". It can be a command on your machine, or an API call to your favorite SaaS

2/ Connector: A collection of tools. MCP is another name for connectors. Connectors can be cloud apps, local apps, custom etc.

3/ Skill: English language instructions to Claude. It describes how to use a set of tools, in steps, to accomplish a task.

4/ Plugin: Plugins are a packaging mechanism. It is a bundle of related skills and connectors.

5/ Harness: A reasoning and execution system that uses skills and connectors to execute your command. It will reason, loop and hill climb until the task is done as measured by some objective criteria.
